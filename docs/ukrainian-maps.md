# Українські назви й описи стандартних melee-мап (1.31.1)

Усі 203 стандартні melee-мапи гри (49 ROC у `maps/` + 154 TFT у
`maps/frozenthrone/`) отримали українські назву, опис, рядок «грають
гравці», а також підписи «Гравець N» / «Сила N» у лобі.

## Звідки гра бере текст у браузері мап

- Кожна мапа — це MPQ-архів. Внутрішній файл `war3map.w3i` (інформація про
  мапу) не містить назви напряму: у полях name/author/description/suggested
  players лежать посилання виду `TRIGSTR_003`.
- Сам текст живе у `war3map.wts` (та його локалізованих варіантах) у блоках
  `STRING <id>`. Тобто назву й опис міняємо у wts, `w3i` не чіпаємо.
- У мапах 1.31 з CASC всередині лежить **десять** wts-варіантів: базовий
  англійський `war3map.wts` + 9 локалізованих копій (de/es/fr/it/ko/pl/ru/…,
  імена блоків у хеш-таблиці MPQ не читаються — Blizzard шифрував listfile).
  Заміняємо текст **в усіх** варіантах одразу, тож будь-яка мова інтерфейсу
  гри показує український текст.
- У 29 мап (w3i версія 27/28) перед рядками є додаткові 16 байт — це
  враховано в парсері (`tools/wc3map.py::parse_w3i`).

## Механізм перевизначення (override)

- Гра читає мапи з CASC, але файли, покладені в папку `Maps/` ігрового
  кореня за тим самим відносним шляхом, перекривають їх (той самий механізм
  локальних файлів, що й для `Units/`, `UI/`; лаунчер сам створює `Maps/`
  і вже клав туди 4 Community-мапи).
- Відповідність шляхів: CASC `war3.w3mod\maps\frozenthrone\(2)amazonia.w3x`
  → диск `Maps/FrozenThrone/(2)amazonia.w3x`. macOS APFS чутливий/нечутливий
  до регістру залежно від налаштування тому, тому перевірка рівності шляхів
  робиться case-insensitive (див. `verify` у build-скрипті). Російський
  мовний пакет (`ruru.w3mod`) мап не містить, тож локальних перекладів у
  `.w3mod` не робимо — тільки override у `Maps/`.
- Прямі правки CASC (`Data/`) заборонені й не виконувалися.

## Як це зроблено технічно

1. `tools/casc_read.py` — мінімальний CASC-читач локального сховища гри
   (Data/data/*.idx + data.000/001, root-файл формату TVFS). Витягує всі
   203 мапи в `/tmp/wc3-maps-orig/war3.w3mod/maps/...`.
2. `tools/wc3map.py` — власний мінімальний MPQ-читач/письменник:
   - читає `war3map.w3i`, `war3map.wts` (zlib-сектори, крипто MPQ);
   - `rebuild_map()` перезбирає архів: **незмінені файли копіюються
     байт-у-байт разом з оригінальними блоками** (не перекомпресовуються),
     змінені wts зберігаються нестиснутими single-unit, `(attributes)` /
     `(listfile)` викинуто/перегенеровано; хеш-ідентичності всіх файлів
     (у т.ч. анонімних wts-варіантів) збережено, тож гра знаходить усі
     внутрішні файли як раніше.
3. `tools/map_translations.py` — українські назви (203), описи (171
   унікальних) і рядки гравців.
4. `tools/build_uk_maps.py` — збирає всі мапи в `/tmp/wc3-maps-uk/`,
   звіряє: перезапарс w3i, українська назва присутня в **кожному** wts-блоці,
   набір хеш-ідентичностей файлових записів не змінився, незмінені файли
   байт-в-байт як в оригіналі. Далі `--install` кладе їх у `Maps/`.

## Покриття

- 203/203 melee-мапи з CASC (`maps/*.w3m`, `maps/frozenthrone/*.w3x`),
  у т.ч. `_lv`-варіанти та бонусні (Candy War, Worm War, TD-мапи тощо).
- Не перекладалися: кампанійні мапи (`classic/roc`, `classic/tft` — окрема
  історія), 4 Community-мапи лаунчера (їх немає в CASC).
- Повний список «файл → назва» — `/tmp/wc3-maps-uk/build-report.json`
  (перезбирається скриптом), назви також у `tools/map_translations.py`.

## Як перевірити в грі

1. Перезапустити гру (лаунчер → Play).
2. Створити гру → у списку мап: «Затока Здобичі», «Загублений Храм»,
   «Скеля Черепахи» тощо; в описі — український текст.
3. Якщо якась мапа не показується українською або зникла з переліку —
   це означає, що override не спрацював для неї (див. «Відкат» і
   повідомте розробнику).

## Відкат

- Видалити перекладені файли з `Maps/` (гити їх нема, вони сторонні для
  гри): `find "/Applications/Warcraft III Classic/Maps" -name '(2)*.w3m' -delete` —
  або точніше: кожен встановлений файл перелічений у build-report.json;
  після видалення гра знову показує англійські версії з CASC.
- Резервні копії перекривалися б тільки якщо файл уже існував на диску —
  таких не було (окрім 4 Community-мап, які не чіпалися). Оригінали всіх
  203 мап лежать у CASC і в `tools/` можна перезібрати командою
  `casc_read.py extract`.
- CASC (`Data/`) не змінювався взагалі.

## Відтворення

```bash
uv pip install --python .venv/bin/python mpyq PyCASC   # залежності
.venv/bin/python tools/casc_read.py extract --filter "W3MOD\\MAPS\\" --out /tmp/wc3-maps-orig
.venv/bin/python tools/build_uk_maps.py --install       # збірка + встановлення
```
