# Поточний стан проєкту

> Для агентів: оновлюйте цей файл наприкінці кожної сесії, що змінює стан
> (що зроблено / що далі / рішення). Коротко, з датами. Історія — в git log.

_Оновлено: 2026-11-21_

## Готово
- Текстова українізація гри (меню 1.31, тексти, 203 карти) — встановлена (`docs/install-local.md`).
- Інвентар 2401 голосового файлу, рос. референси, транскрипти: орки, нежить, нічні ельфи (+ селянин).
- Voice bible для 4 рас (`docs/voice-bible/`). Тексти Орчатника (peon) звірені з оригіналом.
- Студія запису v3 (`tools/studio/`): усі раси, дублі/кошик/undo, вибір для гри, оригінал RU/EN.
- Оригінали (`make refs`): EN 2384 з CASC гри (без пари 17, нежить); RU 2401 — з рос. мовного
  пакета репаку (у CASC гри їх немає), без змін.
- CI на GitHub (`.github/workflows/ci.yml`): ruff, тести з Chrome, покриття ≥ 94% (храповик).

- Голоси спільноти (2026-11-22): `voices/<нік>/` (FLAC, CC BY 4.0), `make publish-voice`, `make check-voices`, вибір «чий голос» на расу/юніт/репліку у вікні встановлення. Рішення користувача: ліцензія CC BY 4.0; звичайний git без LFS (≈ 60 МБ на автора; LFS/Releases — пізніше).
## Зараз
- Встановлення в гру: кнопка «Встановити в гру» в студії або `make install-voices` (симлінки юнітів матеріалізуються з відкатом, `tools/install_voices.py`). Попередження про перевантаження мікрофона (бейдж у дублі).
- «Залишити оригінал» (кнопка / клавіша O на картці): для звуків без слів у гру йде НЕОБРОБЛЕНИЙ оригінал RU/EN.
  ⚠ Такі файли лежать у `game-files/` і перелічені в `game-files/.originals.json` `{rel: {lang, sha256}}` — це аудіо Blizzard:
  **публікація голосового пакета мусить пропускати всі rel з `.originals.json`** і ніколи не комітити їх.
- Користувач сам озвучує Орду в студії (`make studio`). Прогрес — у самій студії.

## Далі
1. Транскрипти для людей (є лише селянин) — `tools/transcribe.py`. Англійських транскриптів немає
   (у режимі EN текст показується російський).
2. ElevenLabs — коли користувач дасть ключ (`docs/improve-and-elevenlabs.md`).
3. Місії кампанії — новий каталог у студії (`tools/studio/README.md` → «Розширення»).

## Відомі обмеження
- Python 3.11 (PyCASC тягне requests 2.21). Формат дублів зашитий (`paths.py`: WAV 22050 mono) —
  для місій/обробки, можливо, знадобиться формат на рівні каталогу й мастер 48 кГц.
- Історія git до 2026-11-21 переписана (прибрано корпоративну пошту) — старі клони несумісні.

## Рішення (не переглядати без користувача)
- Локальні TTS (Piper, XTTS-v2, Fish S2-Pro) відхилено за якістю.
- Аудіо гри не публікуємо ніколи. Власні записи — лише добровільно, як пакети `voices/<нік>/` (CC BY 4.0, згода автора); решта аудіо в .gitignore.
- «Вотермарки» в рос. оригіналах були галюцинаціями Whisper («Продолжение следует…»): чищення
  скасовано 2026-11-21, оригінали відновлено (обрізані — `backups/reference-trimmed-by-whisper-*.tgz`).
- Автор комітів у цьому репо — лише особиста пошта (`git config user.email` локально).
