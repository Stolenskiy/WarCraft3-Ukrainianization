# 0002. Пакети голосів: FLAC у звичайному git, CC BY 4.0

Статус: прийнято (власник, 2026-11-22)

## Контекст
Учасники діляться власними записами; потрібен простий PR-процес і зрозуміла ліцензія.

## Рішення
`voices/<автор>/{voice.json, manifest.json, units/<раса>/<юніт>/<файл>.flac}`, FLAC 22050 Hz mono s16; ліцензія CC BY 4.0
(`voices/LICENSE.md`), згода автора (`consent: true`), ШІ-репліки позначені. Звичайний git, без LFS.
`make check-voices` перевіряє формат і відсутність оригіналів гри; `make guard` пускає в git лише ці файли.

## Наслідки
- ≈ 60 МБ на автора; коли пакетів побільшає — Git LFS або GitHub Releases (окреме рішення).
- Код — MIT, пакети — CC BY 4.0, ресурси Blizzard не входять.
- Аудіо поза `voices/` ніколи не комітиться (`.gitignore`, guard, CI).
