# 0005. Транскрипти оригінальних реплік у git

Статус: **Пропозиція — потребує рішення власника**

## Контекст
`data/transcripts-*.json` (42 файли, ≈ 0.5 МБ) містять тексти оригінальних реплік Blizzard (російські, Whisper), що лежать у git.
Це потенційно захищений авторським правом текст; водночас студія й `tools/inventory` без них не показують текст для озвучення.
Файли НЕ видаляти й не переписувати історію без рішення.

## Варіанти
1. **Лишити як є** і задокументувати як цитування для некомерційної локалізації. Ризик: запит правовласника.
2. **Прибрати з git, генерувати локально** (`tools/transcribe.py` з `reference/`, gitignore). Безпечніше; але CI/нові учасники без RU-пакета
   втрачають тексти (тести використовують фікстури, тож CI не страждає).
3. **Лишити лише наші укр. тексти** (voice bible), оригінальні RU-тексти — локально; транскрипти в git — лише поле `duration`.

## Рекомендація
Варіант 3 (за потреби 2): публікуємо власні тексти й тривалості, оригінальні тексти Blizzard тримаємо локально.
Потрібна міграція студії/`catalog.py` (читати текст із локального файлу, якщо він є) і, за бажанням власника,
переписування історії — окреме рішення. До відповіді власника нічого не змінюється.
