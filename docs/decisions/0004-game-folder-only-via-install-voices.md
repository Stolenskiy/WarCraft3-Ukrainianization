# 0004. Тека гри змінюється лише через install_voices із бекапом

Статус: прийнято

## Контекст
`/Applications/Warcraft III Classic` — зовнішня, важко відворотна ціль; `Units/orc/<юніт>` — симлінки
в `Mods/Reforged Models/...`, запис крізь них псує чужі файли.

## Рішення
Усі записи — через `tools/install_voices.py` (`make install-voices`, кнопка студії) або процедуру скіла `game-change`:
сухий прогін за замовчуванням, бекап і `CHANGE-LOG.txt` у `<гра>/Backups/`, маніфест і відкат, симлінки юнітів
матеріалізуються з відкатом. `Data/` і `Mods/` не чіпаємо, нічого не видаляємо.

## Наслідки
- Агент застосовує зміни (`APPLY=1`) лише за явним дозволом власника в сесії.
- Тест `test_install_voices.py` стежить, щоб `Mods/` лишався байт-у-байт.
