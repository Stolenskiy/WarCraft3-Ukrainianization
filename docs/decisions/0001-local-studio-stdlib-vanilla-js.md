# 0001. Локальна студія: Python stdlib + vanilla JS

Статус: прийнято

## Контекст
Студія запису має працювати в кожного учасника без складного середовища: холодний клон → `make studio`.

## Рішення
Сервер — лише Python stdlib (`http.server`) + ffmpeg; UI — vanilla JS/CSS без збірки й npm-залежностей.
Слухає тільки `127.0.0.1`, POST вимагає `X-Studio: 1` і перевіряє Host/Origin.

## Наслідки
- Мінімум залежностей, швидкі тести, нема supply-chain ризику збірки.
- Файли ≤ 300 рядків: ES-модулі без збірки (`web/js`), CSS по фічах, реєстр маршрутів (`routes/`), ядро в `svc/`
  (виконано, `docs/plans/modularize-studio.md`; ліміт стереже `tests/test_docs_sync.py`).
- Нові залежності — лише з вагомою причиною та записом тут.
