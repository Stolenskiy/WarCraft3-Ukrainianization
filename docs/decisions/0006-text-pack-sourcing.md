# 0006. Український текст: джерело, ліцензія, найновіший upstream

Статус: прийнято (2026-11-22)

## Контекст
Текст береться з [warcraft-in-ua/WarCraft3-Reforged-Ukrainian](https://github.com/warcraft-in-ua/WarCraft3-Reforged-Ukrainian):
GitHub API `license: null` → без явного дозволу копіювати його файли в наш репозиторій не можна. Оригінали Blizzard (тексти, шрифти, звук) у git не потрапляють ніколи.
Формат upstream — Reforged: без підсвічених клавіш у Tip; його FDF ламають меню 1.31.1 (`docs/fix-blank-ui.md`).

## Рішення
- У git лише наш код і наші дані: `tools/textpack.py`, `tools/install_pack.py`, `data/targets/*.json`, `data/text-overrides/*.json`.
- Інсталятор завантажує **найновіший** коміт `main` (API `/commits/main`, без токенів і персональних даних), `--ref <sha|тег>`
  фіксує версію. Кеш `data/local/cache/textpack/<sha>/<light|full>/` (gitignored); HEAD не зрушив → без завантаження.
  Коміт і sha256 (архів FULL; для LIGHT — digest списку файлів, кожен файл ще звіряється з git sha1 API) — у кеші та `CHANGE-LOG.txt`.
- Перетворення розбирають структуру, а не накладають diff: підсвічені клавіші (Classic/legacy), FDF 1.31 (структура з власних FDF гри +
  значення upstream за id), шрифти з власної гри (CASC/мовний пакет). Розклад upstream змінився → `TextPackError` до запису в гру.
- `tools/guard_no_audio.py` блокує `*.fdf *.ttf *.srt`, `Units|UI/*.txt`, `_retail_/`, `.txt` з `Tip=/Hotkey=`.
- Власник може попросити явну ліцензію (лист нижче); отримавши CC BY 4.0, рішення переглядаємо.
