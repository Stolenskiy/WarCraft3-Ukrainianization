# Голосовий бібл WC3 Ukrainian Voice — методологія

Це єдине джерело правди про те, **як звучить кожен персонаж**.
Озвучка генерується ТІЛЬКИ за цими документами. Зміна голосу = зміна тут + commit.

## Принципи

1. **Характер > краса.** Голос має одразу впізнаватись. Кожен юніт — архетип,
   і його голос несуперечливо розповідає цей архетип у перші 0.5 секунди.
2. **Расова палітра** — спільний "звуковий світ" раси (обробка, плейспейс),
   індивідуальність — всередині палітри.
3. **Хронометраж.** Українська фраза має вписуватись у тривалість оригіналу
   (див. data/inventory-units.csv). Довші — переписуємо текст, не розтягуємо звук.
4. **Не клонуємо голоси реальних акторів.** Тільки спроєктовані (Voice Design)
   або бібліотечні голоси.
5. **Кожен варіант озвучки = гілка/тег** в audio/experiments: `experiments/<unit>/<voice-vN>/`.
   Порівняння варіантів фіксується в таблиці рішень внизу кожного розділу раси.

## Расові палітри (базові processing-ланцюжки)

| Раса | Простір | Обробка |
|---|---|---|
| **Люди** | сухе, "казарма/собор" | мінімум: легкий EQ, коротке раннє відображення |
| **Орки** | відкритий степ, земля | нижча октава, chest, formant −10%, сухо |
| **Нежить** | холодний склеп | пошепки/subharmonic, мінус низу, холодний довший хвіст |
| **Ельфи** | нічний ліс | яскраві форманти, повітря, середній "лісовий" хвіст |

## Шаблон аркуша персонажа

```markdown
### <unit_folder> — <українська назва>
**Роль/архетип:** ...
**Характер:** 2–3 риси, які чути в голосі.
**Тембр:** вік, стаття, забарвлення, опора, шорсткість/чистота, швидкість мовлення.
**Обробка (race chain + індивідуальні відхилення):** ...
**Мовна манера:** звертання, лексика, типові конструкції.

| Фраза | Український текст | Як озвучувати (емоція, темп, прийом) |
|---|---|---|
| yes1–4 | ... | ... |
| what1–4 | ... | ... |
| yesattack1–3 | ... | ... |
| pissed1–5 | ... | ... |
| warcry | ... | ... |
| death | ... | ... |
```

> **Машиночитаний формат** (його читає студія, `tools/studio/catalog.py::parse_bible`):
> `<unit_folder>` = тека в `reference/units/<race>/`; рядок `| yes1–4 | «A», «B», «C», «D» | … |`
> роздає тексти в «ялинках» по файлах `…yes1…yes4.wav` по порядку. Тексти — лише в «»;
> діапазон має збігатися з реальними файлами. Після зміни — `make test`.
