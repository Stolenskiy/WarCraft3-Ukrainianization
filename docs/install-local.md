# Локальне встановлення: текстовий українізатор + голосовий пак

Інструкція для користувачів Mac-репаку **Warcraft III Classic** (lmmortal-Repack).
Усе ставиться в корінь гри як «вільні» файли поверх CASC — так само, як репак
підключає власні мовні пакети. Нічого не видаляється, відкат — видаленням папок.

> **Шлях гри за замовчуванням:** `/Applications/Warcraft III Classic`
> Усе нижче — відносно цього кореня.

---

## 0. Підготовка (один раз)

Увімкніть читання локальних файлів (у терміналі):

```bash
defaults write "com.blizzard.WarcraftIII" "Allow Local Files" -int 1
```

Перевірка: `defaults read "com.blizzard.WarcraftIII" "Allow Local Files"` → має бути `1`.

## 1. Текстовий українізатор (уже готово у збірці з нашим паком)

Текстова частина складається з чотирьох елементів у корені гри:

| Що | Куди | Звідки взяти |
|---|---|---|
| Назви юнітів, здібностей, предметів | `Units/*.txt` | проєкт [warcraft-in-ua](https://github.com/warcraft-in-ua/WarCraft3-Reforged-Ukrainian), папка `FULL[Interface and campaings]/_retail_/Units` |
| Підказки, тригери, описи | `UI/*.txt` | той самий проєкт, `_retail_/UI` (лише `*.txt`, **не** `framedef/*.fdf`) |
| Меню й інтерфейс (FDF) | `UI/framedef/*.fdf` | **не брати з warcraft-in-ua!** Вони у форматі Reforged 2.x і ламають меню клієнта 1.31.1 (порожні кнопки). Українські FDF у форматі 1.31 — у цьому репозиторії, див. `docs/ukrainian-ui-131.md` |
| Шрифт із кирилицею | `fonts/frizqt__.ttf` | кирилична версія (Nimrod MT) — у мовному пакеті російської локалізації або перепишіть у нас |

⚠️ **Головна пастка:** копіювати `framedef/*.fdf` з warcraft-in-ua у репак 1.31.1
не можна — головне меню стане порожнім. Якщо це вже сталося: видаліть
`UI/framedef/*.fdf` з кореня гри, кнопки повернуться (англійською).

### Камеральні карти

Назви та описи карт живуть **всередині файлів карт** (`.w3m`/`.w3x`), тож їх
не можна «покласти поруч» — потрібен патч метаданих. Усі 203 melee-карти вже
пропатчені в нашому паку (`Maps/<шлях як у CASC>`). Якщо карта не
завантажується — видаліть її файл із `Maps/`, гра повернеться до оригіналу.

### Перевірка

Перезапустіть гру: меню — «Кампанія», «Один гравець», «Налаштування»;
у грі — назви юнітів українською; у списку карт — українські назви й описи.

## 2. Голосовий пак (коли буде готовий)

Принцип: **`.wav` (синтезований або обраний у студії — `game-files/`) кладеться в корінь гри за шляхом оригіналу**
з точною назвою файлу:

```text
Warcraft III Classic/
└── Units/
    └── orc/
        └── peon/
            ├── peonyes1.wav      ← українська озвучка
            ├── peonwhat1.wav
            └── ...
```

Гра підхоплює такі файли автоматично (механізм той самий, яким репак
підключає російську озвучку — перевірено кодом лаунчера, `docs/integration.md`).
⚠ У репаку `Units/orc/<юніт>` часто є симлінком у `Mods/Reforged Models/...` — не копіюйте
крізь нього; безпечна процедура — `.claude/skills/game-change/SKILL.md`.

Пак голосових файлів буде викладено окремим релізом цього репозиторію.
Стан генерації — у `README.md` (розділ «Дорожня карта»).

### Вимоги до wav-файлів

- Формат як в оригіналів: WAV PCM 16-bit, 22050 Hz, mono (перевіряється `afinfo`)
- Тривалість: у межах +10% від оригінальної фрази
- Без обрізаних початків/кінців, без тиші понад 0.3 с на старті

## 3. Відкат усього

```bash
# текстова частина
rm -rf "Units" "UI" "fonts" "Maps"          # з кореня гри (лізьте лише туди!)

# голосова частина
find . -path ./Tools -prune -o -name "Peon*" -print   # приклад пошуку своїх файлів
```

Або точково: кожен встановлений нами елемент має бекап у
`Backups/fix-20261121/` і `Backups/fix2-ukrainian-ui/` з SHA-256 і командами
відкату в `CHANGE-LOG.txt`.

---

## 4. Що робити, якщо щось зламалось

| Симптом | Ліки |
|---|---|
| Порожні кнопки меню | Видаліть `UI/framedef/*.fdf` з кореня гри |
| Квадратики замість літер | Поверніть оригінальний `fonts/frizqt__.ttf` — ваш шрифт без кирилиці |
| Карта не завантажується | Видаліть її файл із `Maps/` у корені гри |
| Українська зникла після «repair» у лаунчері | Лаунчер перезаписав файли своїми — повторно скопіюйте наш пак |
